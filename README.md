# Лабораторная работа №2
## Управление процессами в ОС и обеспечение обмена данных между процессами посредством каналов

**Вариант 16**

### Описание
Реализованы две независимые программы: parent.exe (родительский процесс) и child.exe (дочерний процесс). 
Взаимодействие осуществляется с помощью анонимных каналов Windows:
- Pipe1: parent -> child (stdin)
- Pipe2: child (stderr) -> parent

Правило проверки строк: строка считается корректной, если она оканчивается на . или ;. 
Корректные строки передаются дочерним процессом в файл out.txt (через перенаправление stdout), некорректные выводятся в stderr и передаются родителю через Pipe2 с отображением на консоли.
